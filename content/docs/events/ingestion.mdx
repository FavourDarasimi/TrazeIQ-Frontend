## POST /api/v1/events/

Authenticate with your project's API key in the `X-API-Key` header. The endpoint responds in milliseconds — AI analysis, alerting, and realtime delivery all happen asynchronously.

<Callout variant="warning" title="Payload cap">
  If `len(message)+len(stacktrace)` exceeds `EVENT_MAX_PAYLOAD_BYTES` (default 100 KB), the request is rejected with `413 PAYLOAD_TOO_LARGE` before any DB work.
</Callout>

## Responses

<ResponseExample title="201 — event stored" status="201 Created" json='{\n  "success": true,\n  "data": {\n    "event": {\n      "id": "evt_9f2c",\n      "message": "TypeError: Cannot read properties of undefined",\n      "fingerprint": "fp_a41d",\n      "environment": "production"\n    }\n  }\n}' />

<Callout variant="tip" title="Dedup is automatic">
  Sending the same error 50 times produces exactly one `ErrorGroup` with `count=50` and one open `Incident` — the fingerprint normalizes line numbers and hashes error type + top frames.
</Callout>
