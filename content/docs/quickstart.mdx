## Send your first event in two minutes

No SDK to install. The integration is a plain HTTPS POST — copy the snippet into your app's error handler and you're done.

<Steps>
  <Step title="Create a project">
    Sign in, create an Organization (you become owner), then create a Project. TrazeIQ generates an API key shown exactly once — copy it before you leave the page.
  </Step>
  <Step title="Drop the snippet into your error handler">
    The snippet above is the whole integration. Wrap it in the catch block where you handle exceptions. The endpoint responds in milliseconds.
  </Step>
  <Step title="Watch incidents appear">
    Repeated errors are deduplicated into a single ErrorGroup → one open Incident, with AI root-cause analysis and alert fan-out. No polling, no babysitting.
  </Step>
</Steps>

<Callout variant="info" title="Two auth surfaces">
  Dashboard reads use your session JWT (`Authorization: Bearer` or `trazeiq_access` cookie). Ingestion `POST /api/v1/events/` uses `X-API-Key` only. Don't send both — they authenticate different principals.
</Callout>
